고추참치회 웹앱 V5.4

핵심 기능
1. 다개월 회비 자동 배분
- 회원 회비 입금 등록 시 입금월부터 월 회비 단위로 자동 배분
- 예: 강상구 150,000원 → 3개월 각 50,000원
- 일부 금액은 마지막 달에 부분 납부로 표시
- 거래 저장 전 배분 결과 미리보기

2. 자동 거래 분류
- 회원 이름 포함 입금 → 회비 자동분류
- 이자 → 입출금통장 이자
- 식당·카페 등 출금 → 식사비 추천
- 총무가 거래 분류를 수정·저장하면 같은 거래명을 학습
- 설정 → 자동분류 규칙에서 학습 현황 확인

3. 월 마감
- 결산 → 월 마감
- 마감 후 해당 월 거래 수정·삭제 차단
- 총무 PIN으로 마감 해제
- 확인 필요 거래가 있으면 경고
- 보고서 미확정 시 자동 확정 가능

4. 회원 사진·캐릭터
- 회원 추가/수정 화면에서 사진 선택
- 사진 대신 고양이·동물 캐릭터 12종 선택
- 홈 납부현황, 회원목록, 미수금, 월 보고서에 표시
- 사진은 자동 축소되어 브라우저에 저장

기존 데이터
- 저장 키는 V5와 동일하므로 기존 회원·거래·보고서 데이터가 유지됩니다.
- 기존 회비 거래는 거래월 납부로 자동 호환됩니다.
