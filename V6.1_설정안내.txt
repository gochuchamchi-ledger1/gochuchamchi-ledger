고추참치회 웹앱 V6.1 — 로그인 및 권한 분리

[추가 기능]
- Firebase 이메일/비밀번호 로그인
- 로그인하지 않은 회원: 장부 조회 가능
- 일반 로그인 회원: 조회 가능
- 총무 이메일 계정: 거래·회원·결산 수정 및 클라우드 업로드 가능
- 로그아웃 시 즉시 조회 모드 전환
- Firestore 보안 규칙 파일 포함

[1. GitHub 업로드]
1) ZIP 압축 해제
2) 기존 GitHub 저장소 파일 전체 덮어쓰기
3) Commit changes
4) 접속:
https://gochuchamchi-ledger1.github.io/gochuchamchi-ledger/?v=610

[2. Firebase 이메일 로그인 켜기]
1) Firebase 콘솔 왼쪽 메뉴
2) 보안 → Authentication
3) 시작하기
4) 로그인 방법(Sign-in method)
5) 이메일/비밀번호 선택
6) 첫 번째 '이메일/비밀번호' 사용 설정 ON
7) 저장

[3. 최초 총무 계정 등록]
1) V6.1 앱 → 설정 → 이메일 로그인
2) '처음 계정 만들기'로 총무 이메일 계정 생성
3) 설정 → 현재 계정을 총무로 등록
4) 기존 초기 등록 PIN 입력 (기본값 1234)
5) 등록 완료 확인

[4. Firestore 보안 규칙 적용 — 반드시 최초 총무 등록 후]
1) Firebase 콘솔 → Firestore → 규칙
2) firestore.rules 파일 내용을 전체 복사
3) 기존 규칙을 전부 교체
4) 게시(Publish)

주의:
- 규칙을 먼저 적용하면 최초 총무 이메일을 등록할 수 없습니다.
- 총무 등록 후 규칙을 게시하세요.
- 테스트 모드 규칙은 만료 전에 반드시 교체해야 합니다.
- 비밀번호는 앱 코드나 채팅에 공유하지 마세요.
