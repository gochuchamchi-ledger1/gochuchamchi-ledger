고추참치회 V4

주요 기능
- 카카오뱅크 엑셀 업로드 전 미리보기
- 신규 / 중복 / 확인필요 건수 표시
- 중복 거래 자동 제외
- 신규 거래 선택 후 반영
- 최근 업로드 이력 20건 저장
- 미수금 계산 시작월 설정
- 기본값: 2026년 8월부터 자동 계산
- 2026년 1~7월 카카오뱅크 내역과 미수금 0원 유지

업데이트 방법
1. ZIP 압축 풀기
2. GitHub 저장소의 Upload files
3. 폴더 안 파일 전체 선택
4. Commit changes
5. 약 2~3분 뒤 아래 주소 확인
https://gochuchamchi-ledger1.github.io/gochuchamchi-ledger/?v=40

사용 방법
- 거래 → 카카오 업로드
- 파일 선택
- 미리보기에서 신규/중복 확인
- 반영할 신규 거래 체크
- 선택 거래 반영
