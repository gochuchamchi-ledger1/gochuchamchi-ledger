고추참치회 웹앱 V5.3

추가 기능
1. 총무 서명 등록
- 설정 → 총무 서명 등록
- 사진 또는 PNG 선택
- 월 회계보고서와 모임보고서 화면/PNG에 자동 표시

2. 승인 도장 등록
- 설정 → 승인 도장 등록
- 직접 만든 도장 이미지 등록
- 미등록 시 기본 승인 완료 도장 사용

3. 모임사진 관리
- 사진 최대 3장
- ← / → 버튼으로 순서 변경
- ★ 버튼으로 대표사진 지정
- PNG 저장 시 실제 첨부사진 표시

4. 저장 안정화
- PNG 변환 실패 시 최대 3회 자동 재시도
- 저장 중 중복 실행 방지
- 보고서 제목을 반영한 파일명 자동 생성
