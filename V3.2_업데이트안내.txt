고추참치회 V3.2 안정화판

수정 내용
- 하단 메뉴 버튼 동작 안정화
- 초기 회원 및 거래 데이터 표시 복구
- 외부 엑셀 모듈 때문에 앱 전체가 멈추는 문제 방지
- 엑셀 모듈은 업로드 버튼을 눌렀을 때만 불러오도록 변경
- 잘못된 이전 저장 데이터와 분리
- 서비스워커 캐시 버전 갱신

업데이트 방법
1. ZIP 압축을 풉니다.
2. GitHub 저장소 Upload files에서 폴더 안 파일 전체를 선택합니다.
3. Commit changes를 누릅니다.
4. 2~3분 후 앱 주소를 새로고침합니다.
5. 기존 설치 앱이라면 완전히 종료 후 다시 실행합니다.

확인 기준
- 현재 잔액과 회원 납부현황이 표시됨
- 홈/거래/회원/결산/미수금/설정 버튼이 모두 이동됨
