고추참치회 웹앱 V5.2 기능 추가

추가 기능
1. 모임사진 첨부
- 모임보고서 작성 화면에서 최대 3장 선택
- 모바일 카메라/갤러리 사용 가능
- 사진 자동 축소 저장
- 모임보고서 A4 화면 및 PNG/PDF에 표시
- 수정 시 사진 삭제 및 교체 가능

2. QR 코드 자동 표시
- 월 회계보고서와 모임보고서 하단에 앱 접속 QR 표시
- 보고서 번호 자동 생성

3. 총무 승인 도장
- 월 회계보고서는 '총무 작성·확정' 후 승인 완료 도장 표시
- 모임보고서는 총무 저장 시 승인 완료 도장 표시

4. 기존 기능 유지
- 보고서 화면 잘림 방지
- PNG 저장, PDF/인쇄, 공유
- 기존 거래 및 보고서 데이터 유지

주의

- 사진이 너무 많으면 저장공간이 부족할 수 있어 최대 3장으로 제한했습니다.
